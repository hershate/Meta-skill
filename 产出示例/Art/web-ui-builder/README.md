# Web UI Builder

## 简介

设计驱动的前端 UI 页面生成器。在编码前通过**设计方向框架**（目的/基调/约束/差异化）确保产出具有独特视觉风格，避免通用的 AI 美学痕迹。生成纯静态单文件 HTML（内嵌 CSS + JS），双击即可在浏览器中查看，无需任何构建工具或 npm 依赖。

适用于快速原型、产品展示页、仪表板、表单页面、Landing Page 等场景。

```
web-ui-builder/
```

## Workflow 说明

1. **建立设计方向** — 四步框架（目的/基调/约束/差异化），确保设计有意识而非随机
2. **收集需求** — 页面类型、布局、配色、字体、核心元素、数据内容
3. **设计驱动的 HTML 生成** — 基于设计方向生成包含排版系统、配色方案、布局创新、视觉纹理、动效和交互的高质量 HTML
4. **浏览器打开** — 自动在 Windows 默认浏览器中打开
5. **AI Slop 测试与输出报告** — 检查是否避免 AI 风格，提供自定义修改指引

## 设计方向框架

本 Skill 的核心特色——编码前先确定设计方向：

| 步骤 | 内容 |
| --- | --- |
| **① 目的** | 页面解决什么问题的、目标用户、使用场景 |
| **② 基调** | 从 10 种极致风格中选择（极简/奢华/编辑/粗野/趣味/复古/有机/工业/丰富/粉彩） |
| **③ 约束** | 技术限制、可访问性、品牌规范 |
| **④ 差异化** | 让人记住的独特要素 |

## AI Slop 测试

生成页面后自动执行质量检查：

- 避免 Inter/Roboto/Arial 等 AI 通用字体
- 避免紫色渐变/青色深色等 AI 模板配色
- 布局包含非对称或网格打破元素
- 背景有纹理/渐变而非纯色
- 动画使用 expo easing 而非 bounce

## 技术细节

### 依赖

无外部依赖，仅需 Claude Code 内置工具。生成的 HTML 页面也无需任何 npm 包。

可选 CDN（根据设计基调自动选择）：

- **Google Fonts** — 展示字体和正文字体
- **Chart.js 4.x** — 数据可视化图表（仪表板类页面）
- **Lucide Icons** — SVG 图标库

### 使用的工具

- `Read` — 读取项目中的现有文件作为参考
- `Write` — 生成 HTML 页面文件
- `Edit` — 修改已有页面
- `Bash` — 调用 `start` 命令在浏览器中打开页面
- `Glob` — 查找项目中已有的 UI 文件
- `WebSearch` — 验证 CDN URL 有效性

### 输出说明

- 生成的 HTML 文件位于 `web-ui-builder/output/` 目录
- 文件命名采用 `<page-type>-<design-tone>-<descriptor>.html` 格式
- 生成后自动在默认浏览器中打开
- 每个 HTML 文件完全自包含，可单独复制到任意位置使用

## 支持的页面类型

| 类型 | 设计特征 |
| --- | --- |
| 仪表板 | KPI 卡片、图表、数据表格、Tab 切换、工业/极简风格 |
| 表单页面 | 字段验证、密码强度、实时反馈、趣味/极简风格 |
| 列表/表格页 | 搜索过滤、排序、分页、行操作、工业实用风格 |
| 产品展示页 | Hero 区、特性网格、对比表、FAQ、编辑/杂志风格 |
| Landing Page | 非对称 Hero、CTA 按钮、功能介绍、奢华/编辑风格 |

## 注意事项

- 生成的页面是**纯静态**的，不包含后端逻辑或数据库
- 设计基调决定所有后续决策——基调一致比单个元素完美更重要
- 页面首次打开可能需要网络（当使用了 Google Fonts 或 Chart.js 时）
- 如需离线使用含 CDN 的页面，可下载对应资源到本地并修改引用路径
- Windows 下通过 `start` 命令打开浏览器，需确保系统已安装浏览器
- 生成的页面不包含任何跟踪或分析脚本
- `oklch()` 支持 Chrome 111+、Firefox 113+、Safari 15.4+。需兼容旧浏览器时请添加 hex 后备色
