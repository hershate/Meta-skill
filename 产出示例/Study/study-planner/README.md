# Study Planner — 学习路线规划

## 简介
自动为初学者生成结构化、渐进式的学习路线规划。当你面对一个陌生的技术领域、不知从何下手时，帮你分解学习目标、规划学习阶段、推荐学习资源、安排实践练习，让学习之路清晰可见。

## 目录结构
```
study-planner/
├── SKILL.md           # 技能主文件（Claude Code 指令）
├── README.md          # 本文件（使用说明）
├── plans/             # 生成的学习计划文件存放目录
└── references/        # 补充文档（预留）
```

## 安装方式
1. 将 `study-planner/` 目录复制到项目下的 `.claude/skills/` 中
2. 重新启动 Claude Code
3. 直接在对话中输入关键词即可自动激活

## 使用方式

### 直接提问
在对话中直接告诉 Claude 你想学什么：

- "我想学前端开发"
- "我想学数据分析"
- "I want to learn Rust"
- "从零开始学摄影"
- "给我一个学习 Python 的路线"

Claude 会自动激活该 Skill，为你规划学习路线。

### 推荐的提问方式
完整的信息能帮你得到更贴合的计划。如果目标太宽泛（如"我想学编程"），
Claude 会主动追问细化方向，引导你选择感兴趣的具体领域：

> "你想学哪方面的编程？网页开发、数据科学、还是移动 App？不同的方向学习路线不同。"

> "我想学前端开发，零基础，每天能学 2 小时，目标是能找到工作。"

> "I want to learn machine learning. I have basic Python knowledge. I can study 1 hour per day."

## Workflow 说明
1. **解析需求** — 明确你想学什么、目前水平如何、学习目标和可用时间
2. **知识分解** — 将目标拆解为知识依赖关系图，确定学习顺序
3. **阶段设计** — 设计 3-5 个循序渐进的学习阶段，每个阶段有明确目标
4. **资源搜索与验证** — 搜索各阶段学习资源，并通过 WebFetch 逐一验证链接有效性和内容适合度
5. **生成计划** — 输出结构化学习计划文件，内嵌已验证的可靠资源链接（✅ 标记）
6. **学习曲线验证** — 对计划做 5 项质检（依赖闭环、难度跨度、认知负载、里程碑可行性、空白分析），确保学习曲线平缓
7. **呈现与调整** — 摘要展示并告知可调整

## 技术细节

### 使用的工具
- `Read` — 读取用户输入
- `Write` — 写入学习计划文件到 `plans/` 目录
- `WebSearch` — 搜索各阶段的学习资源
- `WebFetch` — **验证资源链接有效性**（HTTP 200 检查）并扫描内容判断是否适合自学

### 严格的链接验证机制
所有内嵌到学习计划中的资源链接都经过双重验证：
1. **可达性验证** — 使用 WebFetch 确认 URL 返回 HTTP 200（非 404/403/超时）
2. **内容适合度验证** — 扫描页面标题和内容结构，判断是否匹配当前学习阶段
3. **状态标记** — ✅ = 已验证可访问且内容适合，⚠️ = 存疑需自行确认，❌ = 无效已剔除

**禁止编造链接**：如果某阶段搜索不到可用资源，会给出搜索关键词建议，而非编造不存在的链接。

### 学习曲线质检（5 项检查）
生成计划后自动执行 5 项验证，确保学习路径平滑可执行：

| 检查项 | 内容 | 门槛 |
|--------|------|------|
| 依赖闭环 | 每阶段的前置知识是否在之前都学过？ | 无前置缺失 |
| 难度跨度 | 相邻阶段难度差是否 ≤ 2 级？ | ≤ 2 级 |
| 认知负载 | 每阶段 3-6 个知识点是否合理？ | 3-6 个 |
| 里程碑可行性 | 每阶段的实践目标能否用已有知识完成？ | 无超前依赖 |
| 空白分析 | 从初学者视角通读，有无遗漏环节？ | 无逻辑跳跃 |

任何检查失败都会触发自动修正，修正通过后才呈现给用户。

### 无需额外依赖
本 Skill 完全基于 Claude Code 内置能力工作，无需安装任何额外工具或库。

### 输出说明
- 学习计划保存在 `study-planner/plans/<topic-slug>.md`
- 每个计划包含：元数据头、阶段概览、前置知识、阶段详情、资源和练习、里程碑
- 可直接打开查看，也可继续对话让 Claude 调整

## 注意事项
- **学习计划基于默认假设**：每天 1-2 小时学习时间。如果你时间不同，告知后可调整
- **资源优先选择免费内容**：尤其是入门阶段，优先推荐交互式教程和视频
- **领域通用**：适用于技术类和非技术类学习（编程、设计、摄影、语言等）
- **快速变化的领域**：如前端框架、AI 工具，计划会侧重不易过时的底层基础知识
- **如果计划不合适**：直接告诉 Claude 调整（"时间太紧了"、"我想多做项目"等）
- **链接经过真实验证**：所有资源链接都通过 WebFetch 确认可访问后才会内嵌，不会编造不存在的链接
- **部分网站可能被屏蔽**：如果某些网站因反爬机制无法自动验证（如需要登录），会在计划中标注 ⚠️ 提示自行确认
- **学习曲线经过自动验证**：生成计划后自动执行 5 项质检，确保不存在跳跃过大、缺失必要前置等问题
- **质检失败会自动修正**：如果发现计划存在问题，会先修正再呈现，不会直接把未经验证的计划输出给你

## 适用人群
- **绝对零基础**——不了解该技术，完全不知道从何开始
- **有一定基础想转方向**——了解编程但想学新领域
- **自学迷茫者**——看了很多资料但感到杂乱，需要系统规划
