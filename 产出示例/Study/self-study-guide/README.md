# Self-Study Guide

## 简介

将用户提供的大纲、知识点列表或课程提纲，自动转化为系统化的自学材料。该 Skill 会拆解学习单元、搜索补充资料、设计练习和复习环节，帮助用户在没有老师指导的情况下独立掌握知识。

## 目录结构

```
self-study-guide/
├── SKILL.md                # 技能主文件
├── README.md               # 本文件
├── study-materials/        # 生成的学习材料输出目录
│   └── index.md            # 学习计划与索引（自动生成）
├── references/             # 补充文档（预留）
```

## 安装方式

1. 将 `self-study-guide/` 目录复制到项目 `.claude/skills/` 下
2. 重新启动 Claude Code
3. 使用 `/self-study-guide` 或触发关键词激活

## 使用方式

### 斜杠命令

`/self-study-guide <大纲或知识点内容>` — 直接提供内容生成自学材料

```
/self-study-guide 我想学 Python 基础：变量、条件判断、循环、函数
```

### 自然语言触发

直接描述需求即可自动激活。例如：

- "帮我整理这些学习资料，生成自学指南"
- "我需要一份关于微积分基础的自学材料"
- "根据这个大纲帮我做一套学习计划"
- "把这些知识点整理成我能自学的内容"

### 自动触发关键词

自学、学习大纲、知识点、自学资料、学习指南、self-study、study guide、学习计划、自学指导、整理学习资料

## Workflow 说明

1. **解析输入** — 读取用户提供的大纲或知识点列表，识别结构和依赖关系
2. **拆分单元** — 按知识依赖和体量拆分为学习单元（每单元 30-60 分钟）
3. **搜索资料** — 对每个核心概念搜索补充教学资料
4. **生成材料** — 为每个单元创建完整的学习文件（概念 + 示例 + 练习 + 检查）
5. **生成索引** — 创建学习路线图和复习计划

## 技术细节

### 使用的工具

- `Read` — 读取用户提供的输入和大纲
- `Write` — 在 `study-materials/` 下写入学习材料文件
- `WebSearch` — 搜索补充教学资料

### 输出说明

所有生成的学习材料保存在 `self-study-guide/study-materials/` 目录下：
- `index.md` — 学习路线图、单元导航和复习计划
- `01-单元名称.md` — 每个学习单元的完整材料（概念、示例、练习、总结）

单元数量较多时会按模块分组存放（`01-模块名/`）。

## 适用场景

| 场景 | 说明 |
|------|------|
| 课程学习 | 根据课程大纲生成配套自学材料 |
| 技能自学 | 将知识点列表转化为系统化学习路径 |
| 考前复习 | 将考试大纲转化为复习材料和练习题 |
| 知识整理 | 将零散的知识点整合为结构化的知识体系 |

## 注意事项

- 适用于任何学科：编程、数学、物理、语言等
- 学习材料的质量取决于输入大纲的详细程度
- 输入越模糊，需要的追问越多；建议提供尽量详细的大纲
- 生成的 `study-materials/` 目录可以复制分享
- 如果对生成的材料不满意，可以再次调用调整
