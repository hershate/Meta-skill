# Course Material Organizer

## 简介

根据课程大纲和用户所处的学习阶段（课前预习、课后复习、冲刺整理、专项攻克），自动生成与之匹配的结构化学习资料。不同于通用的自学指南，本 Skill 专注于**以课程为单位的阶段性资料整理**，会根据时间预算、当前水平和目标自动调整材料的深度、体量和侧重方向。

## 目录结构

```
course-material-organizer/
├── SKILL.md                    # 技能主文件
├── README.md                   # 本文件
├── output/                     # 生成材料的输出目录（自动创建）
│   ├── index.md                # 会话配置索引
│   └── <课程名称>/
│       ├── preview/            # 课前预习材料
│       ├── review/             # 课后复习材料
│       ├── sprint/             # 冲刺整理材料
│       └── targeted/           # 专项攻克材料
├── references/                 # 补充文档（预留）
├── scripts/                    # 可执行脚本（预留）
└── templates/                  # 模板文件（预留）
```

## 安装方式

1. 将 `course-material-organizer/` 目录复制到项目 `.claude/skills/` 下
2. 重新启动 Claude Code
3. 使用 `/course-material-organizer` 或触发关键词激活

## 使用方式

### 斜杠命令

`/course-material-organizer <课程大纲或需求描述>` — 提供课程信息和需求，开始生成材料

```
/course-material-organizer 帮我整理《数据库原理》的复习资料，学完了前6章
```

### 自动触发关键词

课程资料、课程大纲、预习资料、复习资料、course materials、syllabus、根据大纲整理、学习曲线、整理课程

## 工作流程

1. **需求采集** — 通过提问确认学习阶段、时间预算、当前水平和目标；自动验证参数合理性，检测参数矛盾
2. **大纲解析** — 解析课程大纲结构，识别章节和知识依赖关系
3. **策略定制** — 根据阶段和参数，选择对应的模板和深度策略
4. **搜索补充** — 搜索教学资料、例题、常见错误等补充信息
5. **材料生成** — 按阶段模板生成结构化学习材料
6. **质量校验** — 对生成的材料进行模板合规、内容完整性、一致性等多维度校验（否决项强制修正）
7. **多阶段协同**（如已有历史会话）— 检测已有材料，建立跨阶段索引和衔接指引
8. **索引与报告** — 生成学习计划、复习计划和总览索引

## 核心增强功能

### 参数验证与冲突检测

自动检测用户提供的参数是否存在矛盾（如"零基础 + 只剩 1 天"），主动提示并提供建议策略。

### 材料质量保证框架

所有材料生成后自动执行多维度质量校验：

- **否决项**（硬性门禁）：残留占位符、模板缺失、元数据不完整、空内容文件、内容矛盾 → 强制修正
- **非否决项**（质量评分）：内容深度（30%）、可操作性（25%）、一致性（25%）、来源标注（20%）
- 评分低于 60% 时建议优化后再输出
- 学科适应性规则：根据课程名称自动推断学科类型，调整质量检查侧重

### 多阶段协同（Phase 5）

当用户多次调用本 Skill 生成不同阶段材料时：

- 自动检测历史会话，读取之前的配置参数
- 新旧材料衔接：不重复生成已有内容，复用之前的大纲解析和薄弱分析
- 生成跨阶段索引：所有阶段材料统一导航
- 提供阶段衔接指南，建议最佳学习路径

### 校验流程

```
材料生成 → Step 7 质量校验 → 否决项检查 → 修正 → 重新校验 → 输出报告
```

## 学习阶段说明

### 课前预习（Phase 1）

| 特征 | 说明 |
|------|------|
| 适用场景 | 即将上新课，提前了解内容 |
| 材料特点 | 轻量级，侧重概念引入和前置知识 |
| 关键输出 | 核心概念一览、预习要点、课堂准备问题 |
| 时间策略 | 每节约 5-30 分钟，根据剩余天数调整 |

### 课后复习（Phase 2）

| 特征 | 说明 |
|------|------|
| 适用场景 | 学完课程后系统巩固 |
| 材料特点 | 知识总结 + 例题 + 练习题 + 易错点 |
| 关键输出 | 知识结构图、典型例题、分层练习题、易错点提醒 |
| 时间策略 | 薄弱章节详攻，已掌握章节快速过 |

### 冲刺整理（Phase 3）

| 特征 | 说明 |
|------|------|
| 适用场景 | 有特定知识点或专题需要集中整理 |
| 材料特点 | 按难度分类，用户自定范围，不擅自扩展 |
| 关键输出 | 知识难度分类、知识点精要、速记卡片 |
| 时间策略 | 根据用户时间预算调整深度 |
| 核心规则 | 用户必须提供具体知识点列表，技能不自行决定整理范围 |

### 专项攻克（Phase 4）

| 特征 | 说明 |
|------|------|
| 适用场景 | 有特定薄弱环节或复杂专题需深度突破 |
| 材料特点 | 深度聚焦用户指定的攻克目标 |
| 关键输出 | 概念深度解析、对比辨析、分层练习题 |
| 时间策略 | 概念理解 → 应用练习 → 综合突破 |
| 核心规则 | 用户必须提供具体攻克目标，技能不进行分数分析 |

## 技术细节

### 使用的工具

- `Read` — 读取用户提供的输入和大纲
- `Write` — 在 `output/` 下写入学习材料文件
- `WebSearch` — 搜索补充教学资料、例题、常见错误等

### 输出说明

所有生成的材料保存在 `course-material-organizer/output/` 目录下，按课程名称和学习阶段两级分类：

```
output/
├── index.md                # 会话配置索引
└── 计算机网络/              # 课程名称
    ├── preview/            # 预习材料
    │   ├── overview.md     # 预习总览 + 计划
    │   ├── 01-概述.md      # 各章节预习
    │   └── ...
    ├── review/             # 复习材料
    ├── sprint/             # 冲刺整理材料
    └── targeted/           # 专项攻克材料
```

- 每个材料文件头部包含 YAML 元数据块（阶段、章节、难度分类、预估用时）
- 所有文件为 Markdown 格式，可直接查看、打印或导入笔记工具

## 设计理念

本 Skill 遵循「**难度分类，重点用户自定**」原则：

- **技能不做**：判定"考什么/不考什么"、指定"核心考点"、承诺"分数提升"、使用⭐或🔴🟡🟢标记优先级、在冲刺/攻克模式下擅自添加用户未指定的内容
- **技能只做**：按基础/中等/困难进行难度分类、标注难点/易混淆点/易忘点、提供结构化的知识整理框架
- **用户负责**：在冲刺整理和专项攻克模式下，用户**必须**提供需要整理的具体知识点或专题，技能才据此工作
- **用户定制**：如果用户主动提供了自己判定的重点信息，材料中标注"用户指定"以明确区分

## 参数说明

当您调用本 Skill 时，会询问以下参数。准备好这些信息可以更快得到精准的材料：

| 参数 | 说明 | 作用 |
|------|------|------|
| 课程名称与大纲 | 章节标题列表或知识点清单 | 确定内容范围 |
| 学习阶段 | 预习/复习/冲刺整理/专项攻克 | 选择模板和策略 |
| 时间预算 | 计划用多长时间完成整理 | 控制材料体量 |
| 当前水平 | 零基础/有基础/熟练 | 调整内容深度 |
| 具体需求 | 薄弱环节、希望重点关注的领域 | 倾斜材料篇幅 |
| 知识点列表（冲刺/攻克模式） | 用户**必须**提供的具体知识清单 | 确定整理范围 |

## 注意事项

- 每次调用只执行一个阶段，如需多阶段材料请分次调用
- 冲刺整理和专项攻克模式下，用户**必须**提供需要整理的具体知识点清单，技能不会自行决定
- 本技能不做任何"考试判断"——不会判定"考什么/不考什么"、没有"核心考点"概念
- 材料质量取决于大纲详细程度和参数明确程度
- 生成的 `output/` 目录可以复制分享或备份
- 如果对生成的材料不满意，可以调整参数后重新生成
- 对于无标准大纲的课程，提供知识要点列表即可工作
- 本 Skill 适用于任何学科：理工科、文科、医学、语言等
